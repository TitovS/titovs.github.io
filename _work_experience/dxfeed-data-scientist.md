As a Data Scientist at dxFeed, I applied machine learning methods to financial data, evaluated data quality, and developed tools for financial analysis.

From 2017 to mid-2018, I developed R code for calculating financial indices, following tidyverse principles and incorporating interactive documentation. I worked in a fast-paced environment with weekly deliverables and rapid client feedback.

From mid-2018 to 2019, I contributed to an internal Python library for financial data analysis, developing modules for statistical analysis and data manipulation. Examples of my work included stitching futures contracts into continuous time series, sentiment analysis on Twitter data, and machine learning algorithms for detecting iceberg orders.

From 2019 to September 2020, I was responsible for data analysis and technical implementation of the [EQX index](https://www.unisg.ch/en/research/research-in-focus/elite-quality-index/), developed through a joint research project with the University of St. Gallen in Switzerland. I also contributed to discussions on the index’s design.
