As a Data Scientist at DevExperts (dxFeed), I applied machine learning methods to financial data, assessed the quality of supplied data, and developed tools for financial analysis.

From 2019 to September 2020, I led a joint research project with the University of St. Gallen in Switzerland to build a macroeconomic index. My responsibilities covered the full research cycle, from discussing research design to creating a website presenting the results of data analysis.

From mid-2018 to 2019, I helped develop a Python library for financial data analysis. I wrote analytics modules and worked on the infrastructure for building and distributing the library.

From 2017 to mid-2018, I worked on calculating financial indices in R. The code followed the tidyverse approach and included interactive documentation. My work also included automating financial index calculations using R and Python.
