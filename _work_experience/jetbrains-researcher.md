I joined JetBrains in September 2020 as a software engineering researcher, working on machine learning and empirical studies.

I initiated a research project on Jupyter notebooks, working with several interns on exploratory studies and publishing multiple papers on notebook usage and potential tooling. Two highlights were a [large-scale study of publicly available open-source notebooks](https://doi.org/10.1145/3524842.3528447 "A Large-Scale Comparison of Python Code in Jupyter Notebooks and Scripts") and an [observational study of fine-grained notebook changes](https://doi.org/10.1016/j.jss.2026.112983 "Observing Fine-Grained Changes in Jupyter Notebooks During Development Time"), for which we collected and analyzed a dataset at near-keystroke granularity.

Alongside this project, I became increasingly involved in machine learning for software engineering. In 2023, I led a [Kotlin ML initiative](https://arxiv.org/abs/2405.19250 "Kotlin ML Pack: Technical Report") that produced a suite of datasets, benchmarks, and fine-tuned models for Kotlin. We later explored using the Kotlin compiler in an RLVR setting to improve internal code completion models.

Drawing on my background in social sciences, I also briefly worked as a researcher in the Intelligent Collaboration Tools Lab and helped kick-start the Human–AI Experience Lab, contributing to several studies, including work on [writing assistants](https://arxiv.org/abs/2303.16175 "What Writing Assistants Can Learn from Programming IDEs") and [in-IDE human–AI experience](https://doi.org/10.1145/3643796.3648463 "In-IDE Human-AI Experience in the Era of Large Language Models; A Literature Review").
